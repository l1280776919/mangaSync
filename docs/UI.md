# 界面规范与回归

整体沿用蓝白配色与封面网格。主操作使用蓝色，正文和统计数字使用深灰蓝；错误、警告、成功保留语义颜色。不要给每个统计数字涂不同颜色，也不要叠加大面积渐变、厚阴影或悬浮位移动画。

界面分为导航、页面标题与说明、内容面板、操作栏、作品或任务列表。桌面内容限制最大宽度，标题与面板保持固定间距。封面优先展示，边框与投影适度弱化；卡片、表格切换及所有原有功能保留。

手机端提供漫画库、收藏、搜索、任务四个底部入口，其他页面可从导航抽屉进入。底部留出安全区域与内容空间。收藏批量操作只在选中作品后出现，位于底部导航上方；仍可从页面标题旁全选。漫画库统计默认折叠为可展开摘要。筛选工具栏使用两列或跨列排列，避免连续堆叠过多整行控件。

共享样式位于 `web/src/styles/theme.css`，应用框架位于 `web/src/App.vue`。页面业务行为与请求契约不随视觉改版更改。设置页优先显示账号安全与常用设置，网络诊断放在末尾。

验证：
- `npm test`：前端逻辑回归。
- `npm run test:e2e`：浏览器行为及桌面/手机布局检查。
- `e2e/ui-review.spec.js` 使用模拟账号、作品、任务数据和程序绘制的测试封面，巡检概览、收藏、书库、搜索、任务、账号、设置七页，检查运行错误、横向溢出、导航、批量操作栏及统计展开。
- 默认截图写入忽略提交的 `web/test-results`。可以设置 `UI_REVIEW_DIR` 指定审阅截图目录。截图应使用相同数据与视口进行人工对比，不以像素差异代替阅读层级与操作可用性的判断。
- 阅读器保持独立布局，包含已有的手机与桌面操作回归。测试不代表真实 iOS Safari 或所有浏览器均已验证。
